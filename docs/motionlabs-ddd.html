MotionLabs · DDD 四层架构

动作训练智能辅助平台 · 双目 3D 姿态估计 · OpenSim 生物力学分析

领域核心 — 三个限界上下文

  • • 姿态采集 BC — PoseSession 聚合，管理实时 3D 姿态帧序列
  • • 动作分析 BC — Movement 聚合，标准动作模板 vs 实际姿态对比
  • • 训练辅助 BC — TrainingSession 聚合，记录次数、生成反馈
  • • 跨 BC 通过领域事件异步通信 (PoseCaptured → MQ)

关键战术模式

  • • CQRS — Command(写) / Query(读) 分离
  • • Unit of Work — 多 Repository 事务一致性
  • • 领域事件 — PoseCaptured → RepDetected → Feedback 链
  • • Repository 接口在领域层，实现在基础设施层 (DIP)
  • • 领域服务无状态：滤波、姿态对比、OpenSim 转换

Jetson Orin NX 硬件流水线
