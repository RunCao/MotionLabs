⚡️ PVA 可编程视觉加速器 Programmable Vision Accelerator v2
STEP 1
Census
Transform
5×5/7×7 邻域编码
C(p)=⊗ξ(I(p),I(q))
📐 Census Transform
对每个像素的 5×5 或 7×7 邻域做 Census 变换，生成局部结构描述子（bit string）
C(p) = ⊗_{q∈N(p)} ξ(I(p), I(q))
ξ(x,y)=1 if x<y else 0
→
STEP 2
Cost
Computation
Hamming Distance
Cost(d)=Hamming(Cₗ,Cᵣ(p-d))
📐 Cost Computation
计算左右图 Census 编码的 Hamming distance，搜索范围 d∈[0, maxDisparity)
Cost(d) = Hamming(Cₓ(p), Cᵣ(p-d))
→
★ STEP 3 ★
SGM
Aggregation
★ 核心 · 多方向DP ★
Lᵣ=Cost+min(Lᵣ...)+P₁
🔥 SGM Aggregation (核心)
沿 4 或 8 个方向聚合代价，Semi-Global Matching 核心——多方向动态规划
P₁=8, P₂=32 (可调)
Lᵣ(p,d)=Cost(p,d) + min(Lᵣ(p-r,d), Lᵣ(p-r,d±1)+P₁, minₖ(Lᵣ(p-r,k))+P₂) - minₖ(Lᵣ(p-r,k))
→
STEP 4
Winner
Takes All
取最小代价视差
d*=argmin S(p,d)
📐 Winner-Takes-All
每个像素取最小聚合代价对应的视差，输出整像素精度视差图 S16
d*(p) = argminₒ S(p,d)
→
★ STEP 5 ★
Sub-pixel
Interpolation
★ 1/8 像素精度 ★
抛物线拟合 ×8
🎯 Sub-pixel Interpolation
对 WTA 结果做抛物线/等角拟合，达到 1/8 像素亚像素精度。×8 定点：value/8 = 实际像素
d_sub = d* + (C(d*-1)-C(d*+1)) / (2·(C(d*-1)-2·C(d*)+C(d*+1)))
→
STEP 6
L-R
Consistency
遮挡过滤 ≤1px
|dₗ-dᵣ|≤1
📐 L-R Consistency Check
左右一致性检查，标记遮挡点。阈值 |dₓ-dᵣ| ≤ 1 pixel，无效点标记为 0
