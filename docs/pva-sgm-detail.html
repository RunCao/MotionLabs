PVA SGM · 视差图怎么用？

视差图 = 全画面深度查找表 · ViTPose++ 关节坐标 (u,v) 查表得 Z → 3D
关键认知：视差图和 ViTPose++ 的分工
❌ 路径 A · 经典双目匹配（不采用）
左图 → ViTPose++ → 左 33 点 (u₁,v₁)
右图 → 再跑一次 ViTPose++ → 右 33 点 (u₂,v₂)
手动匹配 33 对关键点 → 逐对求视差 → 三角化
成本：ViTPose++ ×2 (50ms) + 匹配开销 · 太慢
✅ 路径 B · 视差图查表（MotionLabs 实际走法）
左图 → ViTPose++ → 左 33 点 (u,v) 一次
双目 → PVA SGM → 全画面视差图 (每个像素都有深度)
对每个关节: disp = disparity_map[v,u] · 查表 O(1)
Z = B×f / disp · X = (u-cx)×Z/f · Y = (v-cy)×Z/f
成本：ViTPose++ (25ms) + PVA SGM (12ms 并行) · 总瓶颈仍是 GPU 25ms

伪代码：视差图怎么被消费
# === PVA 端 (并行于 GPU) ===
disparity_map = pva_sgm.process(left_img, right_img)  # U16, 1280×720, ×8亚像素

# === GPU 端 (并行于 PVA) ===
keypoints_2d = vitpose.infer(left_img)  # [(u₁,v₁,conf₁), ..., (u₃₃,v₃₃,conf₃₃)]

# === CPU 端 (两路都完成后) ===
keypoints_3d = []
for kp in keypoints_2d:
    u, v = int(kp.u), int(kp.v)
    disp_raw = disparity_map[v, u]          # ← 查表! 关键是这一行
    if disp_raw == -1 or disp_raw == 0:          # 无效 (遮挡/低置信)
        continue
    disp_px = disp_raw / 8.0                 # 亚像素→真实像素
    Z = baseline_mm * focal_px / disp_px    # 深度 mm
    X = (u - cx) * Z / focal_px             # 世界坐标 X
    Y = (v - cy) * Z / focal_px             # 世界坐标 Y
    keypoints_3d.append((X, Y, Z))
