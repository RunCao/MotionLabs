🧠 核心哲学

🎓 学术驱动的递归分解

根植于 WriteHERE 论文（arxiv.org/abs/2503.08275）的两项理论贡献：Heterogeneous Recursive Planning 和 Type Specification。归纳三种基本认知操作：THINK 🤔 · WRITE ✍️ · SEARCH 🔍。

ROMA 是一套"如何把复杂问题拆成可执行小问题"的方法论框架。

🔧 工程化的全能 Harness

定位是 Super Agent Harness — 不只是编排逻辑，而是完整的 agent 运行平台。提供 Web UI、IM 渠道、Sandbox、文件系统、长期记忆、MCP 服务器等全套基础设施。

DeerFlow 是一套"agent 能用的完整操作系统"。

🎯 最佳使用场景

✅ 选 ROMA 当...

  • 需要轻量 agent 编排库嵌入已有 Python 项目
  • 快速实验不同的 agent 任务分解策略
  • 每个模块用不同的 LLM（混合推理架构）
  • 学术研究或原型验证，强调递归分解与验证链
  • 资源受限环境 — pip install 即可，无 Docker

✅ 选 DeerFlow 当...

  • 需要生产级 agent 平台，开箱即用
  • 多渠道 IM 接入 + Web 管理界面
  • 长时间深度任务（minutes → hours）
  • 需要安全的 Docker 代码沙箱隔离
  • 团队协作或多用户场景
  • 字节跳动生态内的云服务集成

💎 一句话总结

ROMA 是一套优雅的 agent 编排方法论 — 教会 agent 如何递归拆解复杂问题，强调认知分工与验证闭环。

DeerFlow 是一套完整的 agent 运行平台 — 给 agent 一个家，有 Sandbox、有记忆、有 UI、能接入 IM、能干一切实事。

二者并非竞争关系，而是不同抽象层次：ROMA 解决 "how to decompose"，DeerFlow 解决 "how to run"。理论上完全可以将 ROMA 的递归分解策略作为 skill 集成到 DeerFlow 中。
